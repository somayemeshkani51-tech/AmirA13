# TeacherPlugin

پلاگین سیستم مدرسه و معلم برای Paper 1.21.1

## ساخت
Java 21 و Gradle لازم است.

```bash
gradlew build
```

فایل خروجی:
`build/libs/TeacherPlugin-1.0.0.jar`

## امکانات فعلی
- TEACHER و LEADER-TEACHER کنار نام بازیکن
- لیدر معلم تمام کارهای معلم را دارد
- لیدر می‌تواند معلم اضافه/حذف کند
- ادمین می‌تواند لیدر معلم اضافه کند
- سیستم امتیاز
- مدارک: دیپلم، فوق دیپلم، لیسانس، فوق لیسانس
- سیستم پایه مدرسه و دانش‌آموز
